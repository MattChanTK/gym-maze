# Backlog

Unbuilt work in priority order (the owner reviews the order). Each item's details: `docs/backlog/<KIND>/<CODE>.md`. Kinds: **APP** features, **OPS** running the product and tooling, **RES** research, **SEC** security (add kinds as needed). A new item takes the next number in its kind; codes aren't reused. Done or dropped: it leaves for [ARCHIVE.md](ARCHIVE.md); [CHANGELOG.md](CHANGELOG.md) records details. Reported problems: [FEEDBACK.md](FEEDBACK.md).

**Impact:** High / Medium / Low. **Effort:** S = a day or less, M = a few days, L = a week or more. **Owner:** who does it next; — = unassigned.
